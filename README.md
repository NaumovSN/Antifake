# 🤖 Антифейк | Орловская область (Telegram Бот)

Этот бот создан для **оперативного сбора и проверки сообщений о фейковой информации** от жителей Орловской области. Пользователи могут отправлять боту текст, медиа (фото/видео) и документы для проверки. Администраторы получают эти сообщения, обрабатывают их и отправляют пользователю вердикт.

## 🚀 Основные возможности

### Для Пользователей (Гостей):

  * **Отправка жалоб:** Легко отправить текст, фото, видео или документ на проверку.
  * **Обратная связь:** Получение ответа от администратора прямо в боте (является ли информация фейком, не фейком или требует дополнительной проверки).
  * **Справка:** Встроенная команда `📋 Справка` для получения инструкций.

### Для Администраторов:

  * **Получение жалоб:** Мгновенное получение всех жалоб в виде пересланного сообщения с инлайн-кнопками.
  * **Обработка жалоб:** Удобная обработка с помощью кнопок:
      * `✅ Фейк`
      * `❌ Не фейк`
      * `⏸️ Без ответа` (для доп. проверки / длительной обработки)
      * `🚫 Игнор` (обработать без ответа пользователю)
  * **Синхронизация:** Когда один админ обрабатывает жалобу, сообщение обновляется у всех остальных админов, чтобы избежать дублирования работы.
  * **Статистика:** Команда `📊 Статистика` для просмотра общего числа обращений, количества фейков и статистики по каждому администратору.
  * **Сброс:** Команда `🗑️ Сброс` для полной очистки базы данных `reports` и сброса нумерации (с подтверждением).

### 👑 Для Супер Администраторов:

  * **Управление Администраторами:** Встроенный инструмент (`➕/➖ Админы`) для добавления, удаления и просмотра списка администраторов через Inline-клавиатуру.
  * **Статический Список:** Супер администраторы могут быть добавлены в статический список в `Bot.py` (`SUPER_ADMIN_IDS`) для гарантированного сохранения прав.

## 🛠️ Технологический стек

  * **Python 3.10+**
  * **`python-telegram-bot` (v20+):** Асинхронная библиотека для Telegram Bot API.
  * **`SQLite3`:** Встроенная база данных для хранения жалоб (`reports`) и данных пользователей/админов (`users`).
  * **`python-dotenv`:** Для безопасного управления переменными окружения (токен, ID админов).

## ⚙️ Установка и запуск

### 1\. Клонирование репозитория

```bash
git clone https://github.com/YOUR_USERNAME/antifake-bot.git
cd antifake-bot
```

### 2\. Создание виртуального окружения (рекомендуется)

```bash
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
.\venv\Scripts\activate   # Для Windows
```

### 3\. Установка зависимостей

Зависимости перечислены в файле `requirements.txt`:

```txt
python-telegram-bot[job-queue]
python-dotenv
```

Установите их:

```bash
pip install -r requirements.txt
```

### 4\. Настройка переменных окружения

Создайте файл `.env` в корневой папке проекта. Он **критически важен** для работы бота и **не должен** попадать в Git (включен в `.gitignore`).

```ini
# Файл .env

# Токен, полученный от @BotFather
BOT_TOKEN="***********************" 
```

> **Важно:** ID администраторов в этом проекте управляются статическим списком `SUPER_ADMIN_IDS` прямо в файле `Bot.py` и динамически через функции Супер Администратора, а не через файл `.env`.

> **Как узнать свой User ID?**
> Напишите боту **@userinfobot** (или аналогичному) и он пришлет ваш ID.

### 5\. Запуск бота

```bash
python Bot.py
```

Бот запустится и начнет принимать сообщения. База данных `bot.db` будет создана автоматически при первом запуске.
